# Sprint 01 - Azure Enterprise Hierarchy

## Sprint objective 

Design the Azure Enterprise Hierarchy for ABC Trading.

## Business scenario

ABC Trading is an international company with:
- Headquarters in Portugal
- Branch office in Germany
 
The Company is migrating from an on-premises environment to Microsoft Azure.
Before deploying any Azure resources, the company must design a proper management structure.

## Learning Objectives

By the end of this sprint, we will understand:
- Azure Management Groups
- Azure Subscriptions
- Resource Groups
- Azure Resources
- Enterprise Hierarchy Design

## Deliverables
  
- Enterprise Hierarchy Design
- Management Group structure
- Subscription Design
- Resource Group Design
- Architecture Diagram
- Documentation
